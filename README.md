## 🚀 How to use

1. **Get the code**
   ```bash
   git clone https://github.com/mikewithoutthemechanics/chef-mongi.git
   cd chef-mongi
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run it**
   See the available commands below and pick the one you need.

### Available commands

| `npm run dev` | vite |
| `npm run build` | tsc -b --noEmit && vite build |
| `npm run preview` | vite preview |
| `npm run typecheck` | tsc -b --noEmit |
| `npm run test` | vitest run |
